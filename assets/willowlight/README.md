# Willowlight village art

Generated with the built-in image_gen tool. The user's screenshot guided the overhead perspective and depth; these are original assets. Source PNGs preserve transparency. `scripts/import-village-art.py` slices and downsamples the atlases, quantizes each frame to 128 colors and bakes the JSON assets used by the editor. Both outputs were 1254 × 1254; slicing uses proportional grid coordinates. Runtime rendering uses integer scaling, I4/I8 palette packing and compressed map data. Source atlases are retained here; app bundles consume the baked resources.

- `village-atlas.png`: sixteen scenery sprites.
- `traveller-atlas.png`: four directions, four walk frames each.

## Scenery prompt

Use case: stylized-concept. Asset type: production game scenery sprite atlas for a top-down 2D village adventure, GBA-era detail with a cozy modern pixel RPG feel. Create ONE transparent 1024x1024 PNG spritesheet in a perfectly regular 4 by 4 grid of 256x256 cells, with exactly one isolated complete object centered within each cell. No grid lines, labels, text, backgrounds or surrounding scenery. Every object fits inside its own cell with transparent margins, no overlap. Camera is fixed orthographic three-quarter overhead, showing front faces and tops, matching a top-down RPG with upright characters. Cohesive restrained palette: moss/emerald foliage, warm ochre wood, muted slate blue metal, terracotta roofs and warm cream plaster. Crisp intentional pixel art clusters at a native 64px-per-cell art resolution enlarged exactly 4x nearest-neighbor to 256px cells, no blur, gradients, vector curves or painterly smears. Gentle top-left light, detailed readable materials, dark teal lower-right shading, subtle short ground contact shadows. Row 1 left to right: large rounded oak tree with visible trunk; tall layered fir tree; ornate curved street lamp with brass lantern; wooden park bench viewed from above and front. Row 2: pair of wooden barrels; stack of two wooden shipping crates; flowering rectangular planter; stone village well with wooden canopy. Row 3: cozy large cream cottage with terracotta roof and visible door/windows; little timber garden shed with blue roof; low stone arched gateway; wooden direction signpost without writing. Row 4: lush compact cuttable shrub; pale irregular boulder; small fountain basin with blue water; stacked sacks beside a potted flowering plant. Make roofs and upper portions larger than their ground footprint to convey depth. Each object visually polished and useful as a standalone transparent game sprite. Do not copy any existing game's assets.

## Traveller prompt

Use case: stylized-concept. Asset type: original pixel RPG character walk sprite atlas with true transparent background. Make ONE 1024x1024 atlas, exact 4 columns and 4 rows, all sixteen cells equally 256x256, one complete small character per cell at exactly the same scale and baseline, centered. No grid, captions, scenery, ground plane, shadow outside character, items or labels. Character: friendly young village adventurer with chestnut side-parted hair, teal short coat and cream scarf, brown belt/satchel, dark blue trousers and brown boots. Cozy detailed GBA-style pixel RPG character, 24x40 native art enlarged nearest-neighbor with crisp pixel clusters, soft top-left light rendered as 5-7 discrete color shades, not smooth gradients. Orthographic three-quarter overhead RPG view showing top of head and face/front or back depending on direction. Row 1: character facing DOWN/south, four walking frames left-foot forward, neutral, right-foot forward, neutral. Row 2: facing UP/north/back toward camera, same four walk phases. Row 3: facing LEFT/west, same four walk phases. Row 4: facing RIGHT/east, same four walk phases. Consistent identity, clothing, proportions, visible hands and both boots. Native character deliberately taller and more detailed than an NES sprite. Full body comfortably within each cell, aligned feet, no weapons. No existing game characters, no watermarks.
