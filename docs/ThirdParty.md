# Third-party code and assets

Runtime exports use the independently installed **LVGL** library; upstream LVGL is MIT licensed. The optional test script downloads pinned upstream tags into ignored `.cache` directories; the engine export does not bundle LVGL. Keep the applicable LVGL notices in your firmware distribution.

Editor dependencies are recorded in package-lock.json: Electron, electron-builder, React/React DOM, CodeMirror/Lezer, Vite, TypeScript, Immer, Lucide React, JSZip, Playwright, tsx and their transitive dependencies. Consult installed package LICENSE files for distribution notices. JSZip is offered under MIT or GPLv3; the MIT option is available. Lucide uses ISC. DM Sans and IBM Plex Mono are bundled locally through Fontsource and carry their font licenses in node_modules/@fontsource; include those licenses when redistributing fonts.

The starter pixel sprites, terrain patterns and synthesized pickup WAV are generated by the source in src/assets.ts. No Unity RPG assets, competitor artwork or external sound files were copied into this project.

The .app includes Electron/Chromium license files plus bundled-library/font notices under Contents/Resources/licenses. Only renderer bundles and native application modules are in app.asar; development node_modules are excluded. The app icon is original procedural artwork matching the editor controller mark.

Native playtesting bundles LVGL 9.4.0 under its MIT license, with upstream headers and a host static library. The pinned commit and license are included in `native-sdk/sdk.json` and `native-sdk/LVGL-LICENSE.txt` in the built app resources. The compiler is supplied by Apple Command Line Tools and is not bundled.

Amber Trail and Willowlight use original generated pixel characters, terrain and maps from `src/examples/art.ts`. Their pickup cue reuses the project's original synthesized WAV. Willowlight is inspired by handheld adventure conventions; no Nintendo/Zelda characters, maps, sounds, textures or engine code were copied.


## Board SDKs and private art packs

The DK builder obtains the pinned upstream board port separately. Its vendor SDK,
BSP, GPU libraries, and upstream LVGL retain their own licensing terms; this
repository's custom license does not replace those terms. The small vendored ST
ADC driver retains its original notices and provenance under
`ports/stm32h7s78/vendor/adc/`. Review vendor redistribution conditions before
shipping a combined firmware distribution.

Import scripts for purchased tilesets and character packs require your own
legally acquired copies. Those packs and the local projects containing their
pixels are not supplied in this public repository.
